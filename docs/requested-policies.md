# Requested policies

Policy capabilities that users have asked for via **Policy chat** but that Salt
doesn't support today. Entries below are appended automatically when the agent
determines a request can't be expressed with Salt's current policy types
(e.g. time-scheduled access, cumulative spend limits, enforced approval flows).

This file is committed to git deliberately — it's the backlog we share with the
Salt team. In future, entries here will auto-create GitHub issues against Salt.
